# Contributing

## Source of Truth
- Keep `spec/openapi.json` as the API contract.
- Define JSON request bodies with named component schemas and `$ref` them from operations.
- Generated API code stays out of version control.

## Before Committing

Run:

```bash
dotnet tool restore
npm run typecheck --workspace apps/worker-ebs
dotnet build apps/desktop/src/Vic3Unofficial.Twitch.Desktop.csproj
```

For Worker deployment confidence, also run:

```bash
cd apps/worker-ebs
npx wrangler deploy --dry-run
```

## Secrets
- Twitch extension secrets, ingest tokens, `.dev.vars`, local desktop settings, and Cloudflare credentials stay out of version control.
- Use `wrangler secret put EXT_SHARED_SECRET` for Worker secrets.
- Treat public repository changes to config files carefully.
- Keep temporary development origins such as `ALLOW_TRYCLOUDFLARE_ORIGINS` explicit and disable them before public release.

## Generated Files
- Worker TypeScript API types are generated with `npm run oas:gen --workspace apps/worker-ebs`.
- Worker route metadata generation expects JSON request body schemas to use `$ref` entries under `components.schemas`.
- Desktop C# API client code is generated by the desktop project build with NSwag.
- Generated output under `apps/worker-ebs/src/generated/` and `apps/desktop/src/Generated/` is ignored.
- If generated code is needed for another app, add a generator script and ignore its output unless there is a clear reason to commit it.
