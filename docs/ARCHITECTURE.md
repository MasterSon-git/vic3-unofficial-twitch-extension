# Architecture

## Components
- Desktop uploader watches Victoria 3 saves, parses game state, and sends `/ingest`.
- Cloudflare Worker validates pairing and ingest requests, stores minimal ingest metadata in KV, and broadcasts accepted snapshots via Twitch Extension PubSub.
- Twitch Extension panel receives state through Twitch Extension PubSub. UI resources such as names, labels, and flags are shipped with the panel itself.

## Data Flow
1. Broadcaster opens the Twitch Extension config view.
2. Config view calls `POST /pair/init` with a Twitch Extension JWT and `channelId`.
3. Desktop app calls `POST /pair/complete` with the pairing code and stores the returned ingest token locally.
4. The config view can read and revoke pairing status for its own channel.
5. Desktop app sends `POST /ingest` for new saves at the configured interval.
6. Worker validates the token, sequence, save hash, payload size, and channel.
7. Worker sends `{ "type": "vic3:snapshot", "payload": ... }` to Twitch Extension PubSub.
8. Twitch delivers the broadcast to connected viewers.

## API Ownership
- `spec/openapi.json` is the API reference and contract.
- Apps generate local types/clients from the spec.
- Generated code is not committed.
- Build checks compare app code against the generated API types.

## Security
- No Twitch extension secrets in desktop or frontend code.
- `/pair/init` validates Twitch Extension JWTs with `EXT_SHARED_SECRET`.
- The Worker signs EBS PubSub JWTs with `EXT_SHARED_SECRET`.
- Ingest tokens are generated by the Worker, stored in the Worker pairing state with a 30-day lifetime, and stored locally by the desktop app.
- Pairing codes allow three failed completion attempts.
- Active channel slots are limited and leased for 24 hours at a time. A valid 30-day pairing can claim a new active slot when the desktop app starts or ingests.
- Reserved channel IDs have priority and can displace the oldest non-reserved active channel.
- Pairings can be revoked from the desktop app with the ingest token or from the Twitch Extension config view with the broadcaster JWT.

## Viewer State
- Viewer state is delivered through Twitch Extension PubSub.
- The Worker handles broadcaster pairing, desktop ingest, and Twitch PubSub publishing.
